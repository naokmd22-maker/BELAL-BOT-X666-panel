# বট প্যানেল — সহজ ও অটোমেটিক ভার্সন

`BOT_PANEL_SPECIFICATION.md`-এর ১৫টা সেকশন অনুযায়ী বানানো একক-ফাইল প্যানেল (`server.js`)। এই ভার্সনে ডিপ্লয় ও কনফিগ করাটা যতটা সম্ভব সহজ ও অটোমেটিক করা হয়েছে।

## 🎯 শুরুতে যা লাগবে (মোটে ২টা জিনিস)

শুধু এই দুটো তথ্য হাতে রাখুন, বাকি সবকিছু ওয়েবসাইট থেকেই সেট করা যাবে:
1. **একটা GitHub রিপো** (এই পুরো ফোল্ডারটা আপলোড করার জন্য)
2. **একটা MongoDB Atlas connection string** (আগের কথাবার্তায় যেভাবে বানিয়েছেন)

## ধাপ ১ — GitHub-এ আপলোড

1. GitHub-এ নতুন **Private** repository বানান
2. "uploading an existing file" থেকে এই পুরো zip-এর সব ফাইল আপলোড করে Commit করুন
3. আপনার বট প্রজেক্টের zip (BELAL-MAX-BOT ইত্যাদি) আলাদাভাবে, নাম **`bot.zip`** দিয়ে, একই রিপোর রুটে আপলোড করুন

## ধাপ ২ — Render-এ ডিপ্লয় (Blueprint দিয়ে, একবারেই সব সেটআপ)

এই প্রজেক্টে একটা `render.yaml` ফাইল আছে যেটা Render-কে সব বলে দেয় — আপনাকে শুধু ২টা জিনিস বসাতে হবে:

1. render.com এ লগইন করুন → **"New +" → "Blueprint"**
2. আপনার GitHub রিপো সিলেক্ট করুন
3. Render নিজেই `render.yaml` পড়ে ফেলবে এবং জিজ্ঞেস করবে:
   - `PANEL_PASSWORD` → আপনার পছন্দের একটা পাসওয়ার্ড দিন
   - `MONGODB_URI` → আগের ধাপে বানানো connection string (username+password বসানো) দিন
4. **"Apply"** — Render বাকি সব (build, start command, secret জেনারেট) নিজেই করে ফেলবে
5. কিছুক্ষণ পর একটা লিংক পাবেন (যেমন `https://bot-panel-xxxx.onrender.com`)

## ধাপ ৩ — ওয়েবসাইট থেকেই বাকি সব সেট করুন (কোনো কোড/env var লাগবে না)

লিংক খুলে পাসওয়ার্ড দিয়ে লগইন করুন। এরপর **⚙️ সেটিংস** ট্যাবে যান:

- **GitHub রিপো** — যেই রিপোতে `bot.zip` রেখেছেন তার লিংক পেস্ট করুন (যেমন `https://github.com/username/repo`)
- **Branch/zip নাম** — সাধারণত `main` / `bot.zip` (ডিফল্ট রাখলেই চলবে)
- **Private রিপো হলে** GitHub Token বসান (Public হলে খালি রাখুন)
- **💾 সব সেভ করুন** চাপুন

এরপর **🏠 হোম** ট্যাবে গিয়ে **🔄 রিস্টার্ট** চাপুন — প্যানেল এখন GitHub থেকে `bot.zip` ডাউনলোড করে বসিয়ে দেবে এবং সাথে সাথে MongoDB-তে ব্যাকআপ করে ফেলবে। লগ ট্যাবে সবুজ ✅ মেসেজ দেখলে বুঝবেন হয়ে গেছে।

**এরপর থেকে:**
- GitHub-এর `bot.zip` মুছে দিলেও সমস্যা নেই — MongoDB-ই এখন মূল সোর্স
- ওয়েবসাইটের ফাইল ম্যানেজার থেকে যা এডিট/ডিলিট করবেন তা সাথে সাথে MongoDB-তে সেভ হয়ে যাবে (লাইফটাইম পার্সিস্টেন্ট)
- বটে appstate/cookie বসানো, চালু করা — সব হোম পেজ + ফাইল ম্যানেজার থেকেই করবেন

## ২৪ ঘণ্টা আপটাইম (ফ্রি প্ল্যানের সীমাবদ্ধতা মোকাবেলা)

Render ফ্রি প্ল্যান ১৫ মিনিট নিষ্ক্রিয় থাকলে ঘুমিয়ে যায়। **UptimeRobot** (uptimerobot.com, ফ্রি) দিয়ে প্রতি ৫ মিনিটে আপনার Render লিংকে পিং করার মনিটর বানিয়ে রাখুন — sleep হবে না। (১০০% গ্যারান্টি না, কিন্তু কার্যকর। সত্যিকারের ২৪/৭ নিশ্চয়তার জন্য Render-এর পেইড প্ল্যান লাগবে।)

## ভবিষ্যতে আপডেট করার সহজ পদ্ধতি

- কোড পাল্টাতে চাইলে: GitHub রিপোতে ফাইল এডিট করুন → Render নিজেই auto-redeploy করবে (Blueprint-এ auto-deploy ডিফল্ট ON থাকে)
- বট কমান্ড/ফাইল পাল্টাতে চাইলে: সরাসরি ওয়েবসাইটের **📁 ফাইল** ট্যাব থেকে এডিট করুন — সাথে সাথে লাইভ হয়ে যায়, রিস্টার্ট ছাড়াই (Hot Reload)
- নতুন কমান্ড ফাইল লিখলে **🧪 টেস্টার** ট্যাবে টেস্ট করে নিশ্চিত হয়ে তারপর লাইভ করুন
- **📊 মনিটর** ট্যাবে RAM/MongoDB স্টোরেজ কতটুকু ভরেছে দেখে বুঝবেন কখন আপগ্রেড লাগবে

## স্থিতিশীলতা / বাগ-প্রতিরোধ ব্যবস্থা (স্বয়ংক্রিয়, কিছু করতে হবে না)

- RAM বেশি হয়ে গেলে প্রতিরোধমূলক নিরাপদ রিস্টার্ট
- ক্র্যাশ হলে exponential-backoff দিয়ে অটো-রিস্টার্ট (একসাথে বারবার রিস্টার্ট করে সার্ভার বন্ধ করে দেবে না)
- ৬ ঘণ্টা পর পর কানেকশন রিফ্রেশ (silent disconnect প্রতিরোধ)
- npm install একসাথে দুইবার চালু হওয়া আটকানো + ৫ মিনিট hang-হলে নিজেই বাতিল
- প্যানেলের কোনো ধাপ (Mongo/GitHub) ব্যর্থ হলেও পুরো সার্ভার বন্ধ হয়ে যায় না — লগে এরর দেখাবে, ওয়েবসাইট চালু থাকবে
- ব্রাউজার-কম্প্যাটিবিলিটি: পুরনো ব্রাউজারেও যেন সাদা পেজ না দেখায়, তার জন্য global error-catcher

## সীমাবদ্ধতা (সৎভাবে)

- Render ফ্রি: 512MB RAM, 0.1 vCPU, ১৫ মিনিট নিষ্ক্রিয়তায় sleep
- MongoDB Atlas M0 ফ্রি: 512MB স্টোরেজ
- `fca-unofficial` অফিসিয়াল Facebook API না — মাঝেমধ্যে silent disconnect হতে পারে, প্যানেল শুধু প্রতিরোধ/অটো-রিকভারি করে, ১০০% ঠেকাতে পারে না
- `node_modules` কখনো ব্যাকআপ হয় না — নতুন ডিপ্লয়ে/রিস্টার্টে `npm install` দরকার হতে পারে (হোম পেজের বাটন দিয়ে এক ক্লিকেই হয়)
